01

File .eml, sotto la lente.

Parsing della struttura MIME, intestazioni, corpo, link e allegati per vedere cosa c’è davvero nel messaggio.

02

Indicatori, non solo un verdetto.

SPF, DKIM, DMARC, dominio, percorso dei server e reputazione rendono il risultato verificabile.

03

Analisi privata per impostazione.

L’elaborazione avviene sul tuo dispositivo. FishSTOP è uno strumento di supporto, non sostituisce la verifica umana.
